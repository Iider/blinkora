## 不可突破的安全边界

- 默认不连接、读取、迁移或修改飞牛现用服务和数据。M2-A 只读快照和后续临时停写预演分别使用了当次明确授权；每次新的停机、写入、配置修改、文件清理或主服务角色切换仍需新的明确授权，不能沿用旧授权。
- S3 测试只使用全新的隔离前缀，不列举、不读取、不复用 `blinkora/`、`blinkora_local/` 或其他现有业务路径。读取数据库中已有业务 key 必须获得独立只读授权；未授权时保持明确待验，不能借维护窗口扩大范围。
- M1 测试只创建合成账号、Workspace、笔记和附件。M2 真实数据仅在隔离副本做可回滚写入 smoke，正式本机副本只读验证；结束时清理已知测试对象，并记录无法清理的残留。
- 密码、AccessKey、`BLINKORA_SECRET`、API token、Workspace token 和 S3 密钥不得进入命令输出、日志、报告或 Git。
- 生产迁移不能省略原始快照、逐表校验、附件哈希、完整性检查和回滚能力。
